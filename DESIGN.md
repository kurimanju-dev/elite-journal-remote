# UI notes

One window, one running relay. Keep Send and Receive settings separate, and stop before switching roles. Use native file pickers and save settings and recent addresses in the user's app config folder.

Show the real phase, errors and transfer totals. Don't guess addresses or counts. Follow the system theme, keep the minimum window size usable, and put text beside status colors.

Companion apps need ordinary local files and change notifications. Keep the overwrite/atomic choice clear.
